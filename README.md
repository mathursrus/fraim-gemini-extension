# FRAIM Gemini CLI Extension

This repository publishes the FRAIM Gemini CLI extension for external discovery.

FRAIM gives Gemini CLI users access to the FRAIM remote MCP server at `https://fraim.wellnessatwork.me/mcp` and adds FRAIM workflow context, a `/fraim` command, and the FRAIM workflow skill.

## Install

Use Gemini CLI's extension installation flow for public GitHub repositories and install this repository as `fraim`.

## Contents

| Path | Purpose |
|---|---|
| `gemini-extension.json` | Gemini CLI extension manifest at the repository root for gallery indexing. |
| `GEMINI.md` | FRAIM context file. |
| `commands/fraim.toml` | `/fraim` slash command. |
| `skills/fraim/SKILL.md` | FRAIM workflow skill. |
